# Security

If you find a security problem in this plugin or in Oath's server, report it privately:
on this repo's **Security** tab, press **Report a vulnerability**. Only Oath sees the
report. Please do not open a public issue.

Tell us what you found and how to see it.

What counts:

- a skill that makes an assistant send more than the client approved,
- an address in the plugin that is not Oath's,
- a way to read or change another client's data through Oath's server.

Only the latest release is supported.
